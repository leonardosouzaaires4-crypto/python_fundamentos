# Python Fundamentos

Repositório criado para registrar minha evolução nos fundamentos da linguagem **Python**, desde os primeiros conceitos de programação até a criação de pequenos projetos práticos.

O objetivo é desenvolver e consolidar conhecimentos de **lógica de programação, estruturas de controle, funções, manipulação de dados e organização de código**.

## Conteúdos estudados

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores matemáticos e lógicos
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`for`, `while`)
* Listas e outras estruturas de dados
* Funções
* Tratamento básico de erros
* Manipulação de strings
* Organização de código
