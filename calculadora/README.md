# Calculadora em Python

Projeto desenvolvido como parte dos meus estudos de **fundamentos da linguagem Python**.

A aplicação realiza operações matemáticas básicas por meio de uma interface no terminal.

## Objetivo

Praticar conceitos fundamentais de programação, incluindo:

* Variáveis
* Entrada de dados
* Operadores matemáticos
* Estruturas condicionais
* Funções
* Saída de dados

## Funcionalidades

A calculadora permite realizar:

*  Adição
*  Subtração
*  Multiplicação
*  Divisão

##  Tecnologias

* Python 3
* Terminal/Console

##  Como executar

Clone o repositório:

git clone https://github.com/leonardosouzaaires4-crypto/python-fundamentos.git

Entre na pasta do projeto:

cd python-fundamentos/calculadora

Execute o programa:

python calculadora.py

## Exemplo

========================
      CALCULADORA
========================

Digite o primeiro número: 10
Digite o segundo número: 5

Resultado: 15
